Safety review · case 002

🧬 Case 002: Alveon-CF

The edit was confirmed. The protein never appeared.

Your role. You are a reviewer on a regulatory safety panel. A sponsor has reported a serious adverse event in an ongoing gene editing trial and submitted the packet below. Your job is not to design anything. It is to work out, from the sponsor's own data and public databases, what happened at the molecular level, and to make a recommendation.

The submission

Alveon-CF is a phase 1 trial of a base editor delivered to airway epithelium by lipid nanoparticle. The participant carries a known pathogenic CFTR variant. A base editor was chosen rather than a nuclease because the correction needed is a single base and no double-strand break is required.

SPONSOR Alveon Bio
PRODUCT ALV-02, LNP, BE4max cytosine base editor + sgRNA
VARIANT NC_000007.14:g.117480096T>C
CLINVAR Pathogenic (VCV000053622)
INTENT revert the patient's C back to the reference T
PROTOSPACER 5'-GACCACGCAGAGGTCGCCTC-3'
PAM TGG
STRAND plus
START chr7:117,480,091
QC RESULT amplicon sequencing, bronchial brushing, day 28
  g.117480096 C>T in 71% of alleles. Intended edit confirmed.

Serious adverse event report

Participant 004. The intended edit was achieved in 71% of alleles, well above the sponsor's 30% threshold for a predicted clinical benefit.

Sweat chloride is unchanged at 102 mmol/L. FEV1 is unchanged. Western blot of brushed airway epithelium detects no CFTR protein of any size, including no truncated species on a gel run to resolve low molecular weight bands.

The sponsor proposes that delivery was insufficient and requests permission to escalate the dose. The data monitoring committee has asked for an independent review first.

If you are not sure where to start

To see the locus: in the UCSC Genome Browser on hg38 enter chr7:117,480,060-117,480,130 and use View → DNA, or export the same region from Ensembl. Paste it into Benchling as a plain DNA sequence and find the protospacer in it.

One thing to be careful about: the reference genome carries the healthy base. The patient does not. Make sure the sequence you reason about is the patient's.

Before you start

Not graded, just for stats. Fill in each box as you go, then submit once at the end.

1Verify the sponsor's claim

Before anything else, establish whether the edit the sponsor reports is the edit they intended, and what it was supposed to achieve.

2Account for the result

The sponsor's reported edit is real, and there is no protein. Reconcile those two facts. Work out the full set of changes this reagent makes at this site, not only the one the sponsor measured, and what each does.

3Evaluate the sponsor's proposal

The sponsor attributes the failure to insufficient delivery and asks to escalate the dose.
