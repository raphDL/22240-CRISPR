🧬 Turn Down the Volume

Same gene. No edits. Less protein.

The case

A 48-year-old has LDL cholesterol that stays dangerously high on the maximum tolerated dose of a statin. Hepatocytes clear LDL from the blood using LDL receptors on their surface. This patient's liver makes a secreted protein that binds those receptors and sends them to be degraded, so fewer receptors survive to do the clearing.

The team wants to test whether turning down that protein helps this patient. Because it's a first-in-patient study, they want an intervention they can stop. Nothing permanent.

Your job: nothing here is mutated. Work out which tool fits the brief, then design where to aim it.

Tools

You'll use Benchling and BLAST for this exercise.

Before you start

Not graded, just for stats. Fill in each box as you go, then submit once at the end.

1Which gene is this?

BLAST the FASTA against the human genome or RefSeq mRNA database to find the top hit. Keep each answer to a few words.

2Bring it into Benchling

Get the gene's reference genomic sequence, not just the mRNA or CDS, and bring it into Benchling.

Hint

Click the + in the top left → DNA/RNA sequence → DNA/RNA sequence → Import DNA/RNA sequence → Import from database → Gene → search for your gene → Genome: Homo sapiens → Import.

If it doesn't work, click here

The most reliable route: on NCBI's Nucleotide database, search <gene symbol>[gene] AND Homo sapiens[orgn] AND refseqgene[filter]. That filters straight to the genomic RefSeqGene record (introns included) and skips picking a transcript entirely. Open the result whose title matches your gene, not a nearby overlapping gene, then Send to → File → GenBank (full) to download a .gb file. Drag that straight into Benchling. Benchling's own Import from Database can be flaky, this skips it entirely.

3Find the start

Align the downloaded file to the reference you just imported. You're not looking for a mutation this time. You're looking for the first base that gets transcribed, the transcription start site (TSS), which is where exon 1 begins.

Careful: the TSS is not the start codon. Transcription begins before translation does.
